# SQL Project – Pizza Hut Sales Analysis

## 📊 Project Overview
This project analyzes Pizza Hut sales data using SQL to derive useful business insights.

## 🗃️ Tables Used
- orders (order_id, order_date, order_time)
- order_details (order_details_id, order_id, pizza_id, quantity)

## 🔍 Key Analysis
- Total number of orders
- Total pizzas sold
- Orders per day

## 🛠️ Skills & Tools
- SQL (MySQL)
- Data Analysis
- Aggregations (COUNT, SUM)
- GROUP BY

- pizza_hut_sql_project.sql
